01 — Diagnóstico

Estado actual del sitio

El sitio wetrainsimulation.com presenta múltiples problemas críticos que afectan la seguridad, el rendimiento y la conversión de visitantes a clientes.

Crítico

🔓 Sitio Hackeado

Se detectó spam SEO inyectado en múltiples páginas: enlaces a wallets de criptomonedas (Phantom, Rabby, Solflare), casinos, y sitios sospechosos de Google Sites. Vector de ataque probable: Revolution Slider desactualizado.

Crítico

⚡ Timeouts Frecuentes

El sitio experimenta caídas y tiempos de carga excesivos, sugiriendo código malicioso consumiendo recursos del servidor o límites del hosting en WP Engine/Flywheel.

Funcional

🛒 Sin E-Commerce

Las ventas de cursos y equipamiento (MTBox, kits de instrumentos) se manejan por contacto directo vía WhatsApp. No existe carrito de compras ni procesamiento de pagos online.

Funcional

📄 Sin Publicaciones

No existe sección de papers científicos. Competidores como Body Interact exhiben 50+ estudios validados. WeTrain no tiene ninguna presencia en PubMed, Google Scholar o ResearchGate.

Estratégico

📱 Redes Sociales Inactivas

Facebook con 552 likes y último post de agosto 2023. Sin presencia en YouTube ni TikTok. Integración con WhatsApp limitada a un widget básico.

Estratégico

🔌 Exceso de Plugins

WordPress con numerosos plugins (WPML, Revolution Slider, PixelYourSite, chat widgets) generando conflictos, superficie de ataque ampliada y complejidad innecesaria.

03 — Solución Propuesta

Stack tecnológico moderno

Migración completa desde WordPress hacia un stack headless que resuelve cada uno de los problemas detectados.

⚛️

Next.js 14+

Framework React con SSR/SSG para rendimiento óptimo, SEO nativo y zero-downtime deploys en Vercel.

📝

Sanity CMS

CMS headless con edición en tiempo real, multi-idioma nativo (ES/EN) y esquemas personalizados para cursos y papers.

🎓

Google Classroom API

Integración REST API para mostrar cursos activos, estado de inscripción y redirección directa al aula virtual.

💳

Mercado Pago

Gateway de pagos líder en LATAM. Checkout Pro con cuotas, transferencia bancaria y billeteras digitales.

💬

WhatsApp Business API

Botón inteligente con mensaje pre-cargado según producto/curso. Integración con catálogo de productos.

📊

Analytics & SEO

Google Analytics 4, Search Console, sitemap dinámico, meta tags estructurados y Open Graph optimizado.

🔒

Seguridad

Sin WordPress = sin plugins vulnerables. HTTPS, CSP headers, rate limiting y deploy inmutable en CDN global.

🌐

Multi-idioma

i18n nativo con Next.js. Contenido gestionado en español e inglés desde Sanity. URLs localizadas para SEO.

Arquitectura del Nuevo Sistema
Desacoplado, seguro y escalable
